# KMod
A fork of ReMod that falls under the GPL Licence 3.0.

## Building:

To build the KMod DLL you need to include all UI references for Unity and VRChat under dependencies or refrences (Depending on the IDE).

## Usage

Include the dll in any project you have for Melonloader mods for VRChat and you can use it the same as normal ReMod with extra features like UI placement.

## Updates

This repo is updated with extra features and fixes per VRChat update, keep a fork of this repo if you want to stay up to date with the latest feature set.
